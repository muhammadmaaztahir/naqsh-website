# NAQSH — Customize Clothing

Official website and online catalog for Naqsh Atelier, featuring custom clothing design concierge and shop ready-to-wear collections.

## Tech Stack
- **Framework:** TanStack Start / Vite / React 19
- **Styling:** Tailwind CSS / CSS Modules
- **Headless CMS:** Sanity Studio (`studio/` folder)
- **Deployment:** Vercel

## Getting Started

```bash
# Install dependencies
npm install

# Run website locally
npm run dev
```

## Sanity CMS Studio
Headless CMS dashboard is located in `studio/`.

- Hosted CMS Studio: [naqsh-admin.sanity.studio](https://naqsh-admin.sanity.studio)
- Run studio locally:
  ```bash
  cd studio
  npm run dev
  ```
